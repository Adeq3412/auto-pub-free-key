# 🤖 Telegram Auto Publisher Bot

Бот для автоматической публикации VPN-ключей в несколько Telegram сообществ с поддержкой разных шаблонов подвалов.

## 📋 Функции

- ✅ **Установщик с интерактивной конфигурацией** - при первом запуске или обновлении запрашивает нужные данные
- 📝 **Управление несколькими сообществами** - разные чаты с разными текстами подвалов
- 💾 **Сохранение истории постов** - отслеживание отправленных сообщений
- 🔐 **Защита администратора** - только админ может отправлять посты
- 🔄 **Умное обновление** - сохраняет старые параметры при обновлении версии

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Первая установка (интерактивная конфигурация)
```bash
node index.js --install
```

Вас попросят ввести:
- **BOT_TOKEN** - получить у [@BotFather](https://t.me/botfather)
- **ADMIN_USER_ID** - ваш Telegram ID (необязательно)
- **Параметры сообществ:**
  - ID чатов (через запятую)
  - Текст подвала
  - Ссылка на инструкцию
  - Дополнительные ссылки

### 3. Запуск бота
```bash
npm start
```

## 🧾 Донорский канал и модерация

Для автоматической модерации и пересылки из донорского канала в другие паблики:

1. Добавьте бота в донорский канал/группу.
2. Дайте боту права администратора в донорском канале, чтобы он мог читать сообщения.
3. Укажите `DONOR_CHAT_IDS` в `.env`.
4. Модератору будет приходить уведомление, и он сможет одобрить или отклонить пост.

### Какие права нужны боту

- `Read messages` или `Can read messages` в донорском канале/группе
- `Send messages` в целевых сообществах
- Лучше дать боту роль администратора в донорском канале и целевых группах, если это возможно

### Команды модерации

- `/pending` - список постов на модерации
- `/approve <post_id>` - одобрить пост
- `/reject <post_id>` - отклонить пост

### Список команд

| Команда | Описание |
|---------|---------|
| `/help` | Справка по командам |
| `/communities` | Список всех сообществ |
| `/config` | Текущая конфигурация |
| `/post <community> <text>` | Отправить пост |

## ⚙️ Конфигурация через .env

Создается на первом запуске. Пример для двух сообществ:

```env
BOT_TOKEN=123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11
ADMIN_USER_ID=123456789

# Основное сообщество
MAIN_CHAT_IDS=-1001234567890,-1001234567891
MAIN_FOOTER_TEXT=💗 С нас ключ - с тебя реакция:
🔥 — Ключи - огонь | 👍— Спасибо
MAIN_HELP_LINK=https://t.me/stretten/8

# INCY сообщество
INCY_CHAT_IDS=-1001234567892
INCY_FOOTER_TEXT=💗 С нас ключ - с Вас реакция:
🔥 — Ключи - работают | 👍— От души
INCY_HELP_LINK=https://t.me/free_incy/5
```

### Добавление нового сообщества

1. Отредактируйте `config.json`:
```json
{
  "communities": {
    "mynewcommunity": {
      "name": "Мое новое сообщество",
      "chatIdsEnv": "MYNEWCOMMUNITY_CHAT_IDS",
      "footerTextEnv": "MYNEWCOMMUNITY_FOOTER_TEXT",
      "helpLinkEnv": "MYNEWCOMMUNITY_HELP_LINK",
      "additionalLinksEnv": "MYNEWCOMMUNITY_ADDITIONAL_LINKS"
    }
  }
}
```

2. Запустите переустановку:
```bash
node index.js --install
```

3. Введите параметры для нового сообщества

## 🔐 Безопасность

- Бот запрашивает ADMIN_USER_ID для защиты от неавторизованного доступа
- Все конфиденциальные данные хранятся в .env (добавлен в .gitignore)
- История постов сохраняется локально

## 🐛 Решение проблем

### "BOT_TOKEN не установлен"
Запустите: `node index.js --install`

### "Не находит сообщество"
Проверьте параметры в `config.json` и `.env`

### "Ошибка при отправке в чат"
- Убедитесь, что чат ID верный (должен быть в формате `-1001234567890`)
- Проверьте, что бот добавлен в группу/канал администратором
