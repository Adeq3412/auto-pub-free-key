# 🎯 Начало работы с ботом

## ⏱️ Быстрая установка (5 минут)

### Шаг 1: Создание бота в Telegram

1. Откройте [@BotFather](https://t.me/botfather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и получите **BOT_TOKEN**
4. Сохраните токен (понадобится при установке)

### Шаг 2: Установка проекта

#### На Windows:
```bash
setup.bat
```

#### На Linux/Mac:
```bash
chmod +x setup.sh
./setup.sh
```

#### Или вручную:
```bash
npm install
npm run install
```

### Шаг 3: Запуск бота

```bash
npm start
```

## 📝 Что будет запрошено при первой установке

### Основные параметры:
- **BOT_TOKEN** - полученный от @BotFather
- **ADMIN_USER_ID** - ваш Telegram ID (опционально, для защиты команд)

### Параметры для каждого сообщества:
1. **Chat IDs** - ID групп/каналов куда отправлять посты
   - Пример: `-1001234567890,-1001234567891`
   - Как найти ID: [@userinfobot](https://t.me/userinfobot) 

2. **Текст подвала** - как сообщество хочет видеть подпись (или оставить по умолчанию)

3. **Ссылка на инструкцию** - ссылка на гайд подключения

4. **Дополнительные ссылки** - премиум, звезды, буст и т.д.

## 💡 Сценарии использования

### Сценарий A: Одно сообщество
✓ Используйте только `main`

### Сценарий B: Несколько сообществ с разными текстами
✓ Используйте `main`, `incy` и добавьте новые при установке

### Сценарий C: Разные тексты для разных групп одного сообщества
✗ Создайте отдельные сообщества в `config.json`

## 🔄 Обновление конфигурации

Если нужно изменить параметры:

```bash
npm run install
```

Бот **автоматически сохранит** старые параметры и попросит только новые!

## 📊 Полезные команды

```bash
# Просмотреть конфигурацию
npm run config

# Просмотреть историю постов
npm run posts

# Добавить новое сообщество (интерактивно)
npm run add-community newcommunity "Название"
```

## 🎮 Управление ботом в Telegram

Отправьте боту команду в Telegram:

| Команда | Что делает |
|---------|-----------|
| `/start` | Приветствие |
| `/help` | Справка по командам |
| `/config` | Показать конфигурацию |
| `/communities` | Список всех сообществ |
| `/post main <текст>` | Отправить пост в основное сообщество |
| `/post incy <текст>` | Отправить пост в INCY |

## 🔐 Как защитить бота

При установке будет запрос:
> Введите ADMIN_USER_ID для управления ботом

Вставьте ваш **Telegram ID** (узнать: [@userinfobot](https://t.me/userinfobot))

После этого только вы сможете отправлять посты!

## 📋 Структура хранения данных

Все данные хранятся локально:

```
.env         ← Конфигурация (приватная)
posts.json   ← История отправленных постов
.version     ← Текущая версия бота
```

## ⚠️ Частые проблемы

### "BOT_TOKEN не установлен"
```bash
npm run install
```

### "Ошибка при отправке в чат"
1. Проверьте форме ID: `-1001234567890` ✓ | `1001234567890` ✗
2. Убедитесь что бот добавлен в группу администратором
3. Проверьте что группа не заблокирована

### "Не видим посты в группе"
- Может быть задержка в Telegram (5-10 сек)
- Проверьте что чат ID верный
- Посмотрите логи: включите `DEBUG=telegraf:*`

### "Нужно добавить 3-е сообщество"
```bash
npm run add-community namenew "Название сообщества"
npm run install
```

## 🚀 Продвинутое использование

### Добавление 2-3 дополнительных сообществ

1. Отредактируйте `config.json` вручную:
```json
{
  "communities": {
    "main": { ... },
    "incy": { ... },
    "mycommunity": {
      "name": "Мое сообщество",
      "chatIdsEnv": "MYCOMMUNITY_CHAT_IDS",
      "footerTextEnv": "MYCOMMUNITY_FOOTER_TEXT",
      "helpLinkEnv": "MYCOMMUNITY_HELP_LINK",
      "additionalLinksEnv": "MYCOMMUNITY_ADDITIONAL_LINKS"
    }
  }
}
```

2. Запустите:
```bash
npm run install
```

3. Введите параметры для нового сообщества

### Запуск бота в фоне (Linux/Mac)
```bash
nohup npm start > bot.log 2>&1 &
```

### Запуск бота в фоне (Windows)
```cmd
npm start
```
Затем нажмите `Ctrl+C` - бот продолжит работать в фоне (в зависимости от терминала)

Или используйте [PM2](https://pm2.keymetrics.io/):
```bash
npm install -g pm2
pm2 start index.js --name "telegram-bot"
```
