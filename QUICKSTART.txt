# ✅ Проект успешно создан!

## 🎯 Что было реализовано

Telegram-бот для автоматической публикации VPN-ключей в несколько сообществ с интерактивным установщиком.

**Основные функции:**
✅ Интерактивный установщик - запрашивает необходимые данные при первом запуске  
✅ Умное обновление - при обновлении сохраняет старые параметры и запрашивает только новые  
✅ Несколько сообществ - разные текст подвалов для разных групп  
✅ Гибкая конфигурация - все через .env переменные  
✅ История постов - сохранение всех отправленных сообщений  
✅ Защита администратора - только админ может отправлять посты

## 🚀 Как начать

### 1️⃣ Установка (первый раз)

**На Windows:**
```bash
setup.bat
```

**На Linux/Mac:**
```bash
chmod +x setup.sh && ./setup.sh
```

**Или вручную:**
```bash
npm install
npm run install
```

### 2️⃣ При запуске вас спросят:

1. **BOT_TOKEN** - получить у [@BotFather](https://t.me/botfather)
2. **ADMIN_USER_ID** - ваш Telegram ID (опционально)
3. **Для каждого сообщества:**
   - ID чатов (через запятую)
   - Текст подвала
   - Ссылка на инструкцию
   - Дополнительные ссылки

### 3️⃣ Запуск бота

```bash
npm start
```

## 💬 Управление ботом в Telegram

Отправьте боту команду:

```
/post main 🎁 Бесплатные ключи...
[содержание поста]
/post incy 🎁 Бесплатные ключи...
/post mycomm [текст]
```

Или используйте:
- `/help` - справка
- `/config` - конфигурация
- `/communities` - список сообществ

## ⚙️ Конфигурация сообществ

**Основное сообщество (main):**
```env
MAIN_CHAT_IDS=-1001234567890,-1001234567891
MAIN_FOOTER_TEXT=💗 С нас ключ - с тебя реакция:
🔥 — Ключи - огонь | 👍— Спасибо
MAIN_HELP_LINK=https://t.me/stretten/8
```

**INCY сообщество (с измененным текстом):**
```env
INCY_CHAT_IDS=-1001234567892
INCY_FOOTER_TEXT=💗 С нас ключ - с Вас реакция:
🔥 — Ключи - работают | 👍— От души
INCY_HELP_LINK=https://t.me/free_incy/5
```

Вы можете добавить столько сообществ, сколько нужно!

## 📝 Обновление конфигурации

Если нужно изменить параметры:

```bash
npm run install
```

Бот **автоматически сохранит старые значения** и откажет только новые!
