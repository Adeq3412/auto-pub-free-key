## 📚 Описание модулей

### `index.js` - Главный модуль
**Ответственность:**
- Проверка первого запуска и обновлений
- Управление версией приложения
- Запуск установщика при необходимости
- Инициализация бота

**Ключевые функции:**
```javascript
checkVersionAndInstall()  // Проверка версии и вызов установщика
startBot()                // Запуск Telegram бота
main()                    // Главная функция приложения
```

### `installer.js` - Установщик конфигурации
**Ответственность:**
- Интерактивное получение данных у пользователя
- Проверка существующей конфигурации
- Сохранение .env файла
- Пропуск заполненных параметров при обновлении

**Ключевые функции:**
```javascript
interactiveInstall()      // Запуск интерактивного установщика
promptForBotToken()       // Запрос BOT_TOKEN
promptForAdminId()        // Запрос админ ID
promptForCommunity()      // Запрос параметров сообщества
loadEnvFile()             // Загрузка существующего .env
saveEnvFile()             // Сохранение .env файла
```

### `bot.js` - Логика бота
**Ответственность:**
- Обработка Telegram команд
- Отправка постов в чаты
- Валидация прав администратора
- Формирование сообщений с подвалом

**Команды:**
```
/start      - Приветствие
/help       - Справка
/config     - Конфигурация
/communities - Список сообществ
/post <key> <text> - Отправить пост
```

### `storage.js` - Управление данными
**Ответственность:**
- Управление историей постов (PostStorage)
- Управление конфигурацией (ConfigManager)
- Сохранение и загрузка данных из JSON файлов

**Классы:**
```javascript
PostStorage {
  addPost()              // Добавить пост в историю
  updatePost()           // Обновить информацию о посте
  getPost()              // Получить пост по ID
  getAllPosts()          // Получить все посты
}

ConfigManager {
  getCommunityConfig()   // Получить конф. сообщества
  getAllCommunities()    // Получить все сообщества
  isConfigured()         // Проверить настроен ли хотя бы 1 сообщество
}
```

## 🔐 Управление конфигурацией

### Иерархия конфигурации

```
config.json (структура сообществ)
    ↓
.env (переменные окружения)
    ↓
storage.js ConfigManager (загрузка в память)
    ↓
bot.js (использование в командах)
```

### Пример: Добавление сообщества

1. **Определение в config.json:**
```json
"newcommunity": {
  "name": "Новое сообщество",
  "chatIdsEnv": "NEWCOMMUNITY_CHAT_IDS",
  "footerTextEnv": "NEWCOMMUNITY_FOOTER_TEXT",
  "helpLinkEnv": "NEWCOMMUNITY_HELP_LINK",
  "additionalLinksEnv": "NEWCOMMUNITY_ADDITIONAL_LINKS"
}
```

2. **Переменные в .env:**
```env
NEWCOMMUNITY_CHAT_IDS=-1001234567890
NEWCOMMUNITY_FOOTER_TEXT=Мой текст подвала
NEWCOMMUNITY_HELP_LINK=https://example.com
NEWCOMMUNITY_ADDITIONAL_LINKS=Дополнительно...
```

3. **Использование в bot.js:**
```javascript
const config = configManager.getCommunityConfig('newcommunity');
// Отправка в config.chatIds[0], config.chatIds[1]...
```

## 🔄 Жизненный цикл поста

```
1. Пользователь: /post main Содержание...
        ↓
2. bot.js парсит команду
        ↓
3. Проверка прав (isAdmin)
        ↓
4. Получение config для "main"
        ↓
5. Форматирование текста с подвалом
        ↓
6. Циклический перебор chatIds
        ↓
7. Отправка каждому чату через Telegram API
        ↓
8. Сохранение в posts.json via storage.js
        ↓
9. Отправка отчета пользователю
```

## 🛡️ Безопасность

### Защита команд
```javascript
function isAdmin(ctx) {
  return !ADMIN_USER_ID || ctx.from.id.toString() === ADMIN_USER_ID;
}
```
- Если `ADMIN_USER_ID` не задан → команды доступны всем (осторожно!)
- Если задан → только этот пользователь может отправлять посты

### Конфиденциальность
- `.env` добавлен в `.gitignore`
- `posts.json` хранит только метаданные
- Токен и ID никогда не выводятся полностью в логах
